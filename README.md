## About 
This Code Editor was made as a college project and can perform powerful operations such as:
- Creation / Opening / Deletion of Files / Folders
- Search functionality for both files & individual words
- Syntax highlighting for many popular languages (C / C++ / HTML / JavaScript / Python, etc.)
- Easy viewing & navigation of files in tree like manner through built in explorer
- Execution of codes using built in terminal instance
- AI integration through OpenAI / Google / Anthropic APIs
- Multiple inbuilt themes for both light and dark mode users

### Running
The builds for your specific OS and architecture can be downloaded from the [koai Website](https://koaicode.netlify.app) or [Releases Page](https://github.com/kuwushagra/koai/releases/latest).

### Updating
koai features inbuilt one-click update functionality, just click on the `koai` button in the top navigation panel and `Check for updates` button should appear under the `About` section.

### Components
- **Tauri 2:** Cross-platform application framework  
- **React 19:** UI development  
- **Rust:** Native backend  
- **CodeMirror 6:** Code editor
